# Security

Do not report credentials, API keys, Wi-Fi passwords, SSH keys, device logs,
or private book data in a public issue.

If a secret was committed, revoke or rotate it first. Removing it from the
latest commit is not enough because Git history is retained. For a private
report, contact the repository owner through the GitHub profile associated
with this project and include only the minimum reproduction details.

The USB-SSH and local-network helpers are development tools. Use them only on
a trusted cable or network and disable them when they are not needed.
